Can this page go live?

We checked fourteen pages against a saved sample report. Nothing here calls Peec. Eight pages are stored in the database. Six examples exist only in this demo.

A page can go live when its address is in the report, the page has text, and a hidden label repeats that same address. How often the page was named can be low, even zero. A missing score holds it back.

What we learned

  • If the address, the text, and the hidden label agree with the report, the page can go live. That is still true when it was named every time, rarely, or not at all.
  • If the address is missing from the report, the page stays held. The same happens when the report lists the page but does not say how often it was named.
  • Empty text, a hidden label that points somewhere else, and a missing label all hold the page back before the report is even used.
  • If the report fails to load, the page stays held, even when that same address would otherwise go live.
