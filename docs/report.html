Content gate lab notes

Fourteen checks against a saved Peec URL report. No live Peec call. Eight rows are in the Supabase pages table. Six copies stay in the lab only.

What the runs showed

  • A URL in the report, with a body and a matching schema, publishes. That includes rates of 1.0, 0.05, and 0.0. A low rate is not a block.
  • An absent URL blocks. So does a row whose citation_rate is null.
  • An empty body, a schema URL that does not match, and a missing schema all block before Peec is consulted.
  • A Peec error blocks even when that same URL would otherwise publish.
